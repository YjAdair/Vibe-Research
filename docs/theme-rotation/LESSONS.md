# 题材轮动开发经验（迁入 Vibe-Research）

来源：`聊斋秘籍-投研` 热点-题材轮动本期（约 2026-09-14 → 2026-09-24）。  
适用：本模块后续迭代，以及任何「对齐目标站交互、自建数据」的市场栏目。

## 1. 先定契约，再写代码

- **对齐对象是功能与语义，不是对方的数据库。** 页面长得像 ≠ 公式已还原；接口 200 ≠ 年度覆盖完成。
- 每个指标写清：分类版本、成员时点、`event_time` / `available_at` / `collected_at`、coverage、status。缺一项就不要标「已对齐」。
- 用「矩阵/契约」文档做验收清单（横排、个股、人气、梯队、涨幅、K 线逐项），避免用总行数或单样板日冒充全量。

## 2. 数据四条铁律（已写入项目协作）

1. **缺失 ≠ 0**  
2. **旧行情 ≠ 停牌**  
3. **采集时间 ≠ 行情时间**  
4. **未来成分快照不可用于过去**

衍生：人气不借邻日；3/5 日聚合不吃 preview；展示「—」与空档横线语义不同。

## 3. 免费优先的正确姿势

- 先证明免费源**语义**是否够用（深度、历史回放、字段），再谈付费补缺。
- 付费：密钥只在后端；未配置具体工具与预算 → **禁止自动调用**；免费恢复后切回免费。
- 「校准层 / 原站透传」只允许开发期对照，商业化前必须替换为自有链路，并在文档标 `optional / replace-before-ship`。

## 4. 读写分离，别在 GET 里补历史

| 该做 | 不该做 |
|---|---|
| collector 定时落库、收盘定稿 | 用户点历史列时偷偷爬一年 |
| 读路径返回 missing + reason | 借邻日或静默降级冒充完整 |
| 今日盘中明确的 refresh / is_real | 把盘中预览写成 final |

经验：人气公开源无历史回放 → 历史空列是诚实结果；补齐只能靠持续采集或更深源，不能前端「再试一次」。

## 5. 分类与代码体系不要偷懒映射

- 目标 801/803（17/18）与东财 BK（14/15）是**两套宇宙**。同名题材 ≠ 同一成员。
- 能力矩阵按 `(taxonomy, level, metric, as_of)` 返回 available/partial/unavailable，而不是 `if plate_type in (17,18): unsupported` 写死后再复制一份分支。

## 6. K 线：宁要净值，不要假蜡烛

- 没有核验过的板指 OHLC，就返回 `series_kind=daily_nav` 折线。
- 禁止用成分收盘价拼 O/H/L/C「看起来像 K 线」。
- 前端必须按 `series_kind` 分支渲染（蜡烛 vs 净值线），并在 UI 文案区分「日线 / 日净值」。

## 7. 梯队：收盘真值优先于盘中叙事

- 免费池常有「池内仍标涨停但收盘未封」。用 `daily_close` 校验改炸、补漏封板，比追 tick 更可复现。
- 与目标站盘中字段（fd_max、精确烂板）不对齐要写进契约「接受差异」，避免无限对拍消耗。

## 8. 对拍与限流

- 目标站对拍接口有 429：批量验收必须节流；对拍是参考，不是入库源。
- 样板题材（如芯片）top10 代码一致只能证明「成分+涨幅链路」，不能证明强度公式或人气深度。

## 9. 协作与尝试上限

- 复杂口径 / 验收：高推理模型；明确补丁：低费用执行模型。工具不能切换时**如实说**，不假装已切换。
- **同一问题最多 3 次**；失败写入待办（证据、已试方案、影响、下一步），换题，禁止空转。
- 遵守当轮时间与额度；提前完成就停，不为「用满时长」扩 scope。
- 中文记实施与遗留；不重复已完成的全文考古，只在新疑点上开刀。

## 10. 前端验收不能代替数据验收

浏览器看见列表 ≠ 当年逐日覆盖。需要：

1. 库内按日审计（或脚本输出 JSON 摘要）  
2. 关键到端样板日人工点验  
3. 契约状态字段在 UI 上可见（缺失原因）

三者缺一，不得在里程碑里写「完成」。

## 11. 迁仓到 Vibe-Research 时注意

- 本模块文档以 `docs/theme-rotation/` 为权威；旧仓题材文档仅归档。
- 接入主仓时：数据纪律并入根 `AGENTS.md`；实现落在独立包/路由前缀，避免和个股六阶段研究、回测账本缠死。
- 产品栏目命名可改（复盘 / 板块中心 / 独立「题材轮动」），**契约字段与状态机不要改名稀释**。
