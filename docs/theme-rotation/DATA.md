# 题材轮动数据架构

版本：1.0 · 2026-09-24 · 模块：`theme-rotation`

## 1. 双轨模型（回答「实时还是落库」）

```
┌─────────────┐     定时/收盘任务      ┌──────────────────┐
│ 免费公开源   │ ───────────────────► │ 本地事实库        │
│ 开盘啦/THS/ │   清洗 · 定稿 · upsert │ plate_* / daily_* │
│ 东财/腾讯…  │                       └────────┬─────────┘
└─────────────┘                                │ GET 只读
                                      ┌────────▼─────────┐
                                      │ 题材轮动前端       │
                                      └──────────────────┘
```

**主路径**：采集器定期拉取 → 清洗 → 写入本地；前端读历史**先查库**，没有则标缺失。  
**不是**：前端每次点击都现拉现洗现存（历史尤其禁止）。

### 读路径例外（仅今日 / 显式开关）

| 场景 | 行为 |
|---|---|
| 横排今日未定稿 | `rank/columns` 可顺带 `refresh_intraday` |
| 个股 `is_real=1` 或今日无收盘日线 | 拉实时价参与排序/展示 |
| K 线校准开关开启且缓存过期 | 按需回源并写日缓存 |
| 驱动消息本地无行 | 开发期可透传校准源（商业化前替换） |

## 2. 核心事实表（逻辑名）

| 事实 | 落库 | 主写入方 |
|---|---|---|
| 题材日强度/涨幅/资金/成交额 | `plate_rank_daily` + day meta | rank collector / refresh |
| 二级目录与成分 | 成员快照（按日） | 开盘啦成员任务 |
| 个股日线 | `daily_close` | 腾讯日 K；北交所补新浪 |
| 人气 | `popular_snapshots` | THS 热股等 |
| 涨停/炸板池 | `limit_pool_snapshots` | 东财当日 / THS 历史 |
| 板指/校准 K 线 | `ths_board_daily` / `plate_kline_origin` | 板指采集 / 可选校准 |
| 驱动消息 | `plate_reason_daily` | 原因采集 |

业务库路径约定：实现侧以工程配置为准（前身项目为 `backend/zzquant.db`，根目录空库勿用）。

## 3. 状态机（日级）

```
missing_input → partial_preview → final
                      ↓
                    stale（超时/过期报价）
```

- `partial_preview`：可进 1 日展示；**不得**进入 3/5 日正式聚合。
- `final`：收盘门禁通过后定稿；重算用修订版，不静默覆盖回测快照。
- 人气 / 梯队池缺日：直接 `missing`，不挪昨天。

## 4. 清洗边界（摘要）

| 域 | 规则 |
|---|---|
| 成分 | 按日快照；父子校验；一级 ≠ 默认同日二级并集（除非证据声明） |
| 涨幅展示 | 行情比较基准与投资总收益因子分列存储 |
| 梯队 | 池 ∩ 成分 → 收盘价校验封/炸 → 补漏封板；L 与区间板分列 |
| K 线 | 无真实 OHLC → `daily_nav`（基值 1000，等权日收益链）；禁止假蜡烛 |
| 人气 | `rank_change` 空保持 null；禁止改写为 0 |

## 5. 采集与回填工具（运维）

迁仓后工具名以仓库 `scripts/` / `tools/` 为准。前身常用能力：

- 题材榜日期轴对齐的涨停池确保 / 年度梯队回填
- 成分日线缺口补采（含 BJ）
- 人气快照日积月累（公开源无历史回放则只能向前攒）

回填必须：**可审计日志、失败不覆盖好数据、达 3 次失败上限停并记待办**。

## 6. 禁止清单

1. 目标站 JSON 写入产品库当正式源。  
2. 东财 BK ↔ 801 静默映射。  
3. 缺失填 0、借邻日、用未来成分回放。  
4. 成交额字段标成换手率。  
5. 未配置密钥/预算时自动打付费 API。
