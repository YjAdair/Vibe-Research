# 题材轮动 PRD（本期收口）

版本：2.0 · 日期：2026-09-24 · 模块：`theme-rotation`  
状态：**本期功能开发收口**；后续在 Vibe-Research 主仓迭代。

## 1. 产品目标

在「热点」场景下提供题材轮动工作台：按交易日横排浏览题材强弱，下钻二级题材与成分，切换个股 / 人气 / 梯队 / 涨幅 / K 线与驱动消息，支撑盘中预览与盘后复盘。

| 要对齐 | 不要做 |
|---|---|
| 目标站的页面结构、交互与**可观察**的计算语义 | 爬目标站接口结果入库当产品数据 |
| 801/803 题材代码体系（分类 17/18） | 把东财 BK 改名成 801 冒充目标分类 |
| 免费优先、密钥仅后端、付费未配置不调用 | 为视觉一致复制原站已知错误数据 |
| 当年年初至今的历史逐日覆盖可审计 | 用「接口 200 / 单测过」代替功能完成 |

## 2. 用户故事与默认交互

1. 打开题材轮动：默认最近 **10** 个交易日横列、Top **12**、**1** 日窗口、**强度**排序（`n_type=9`）。
2. 点选某一列某一题材：底部趋势始终绑**一级**题材日强度与成交额；二级条只过滤下钻对象。
3. 切换模式：个股 / 人气 / 梯队 / 涨幅 / K 线；列轴与题材榜同一套交易日。
4. 缺数据：展示「缺失」及原因码，不画 0、不借邻日、不跨缺口连假线。

## 3. 模式规格（本期已交付语义）

### 3.1 横排榜 + 日趋势

- 事实来源：开盘啦日榜 → `plate_rank_daily`（盘中 `partial_preview` → 收盘 `final`）。
- 聚合：强度用窗口日值均值；涨幅用复合收益；资金用金额求和——字段不可互换。
- 趋势：只读本地日序列；切换 3/5 日排名不改变趋势粒度。

### 3.2 二级与成分

- 二级目录与成员：开盘啦 `SonPlate_Info` / `ZhiShuStockList_W8` 全量分页快照。
- `M(b,t)`：t 日开盘前已可知成员；盘中新成员次日生效；**禁止用今日成分回放历史**。

### 3.3 个股

- `plate_type=18` 直查二级；「全部」用一级并集。
- 历史：成分 ∩ `daily_close`；最新日可 `is_real=1` 拉实时价；今日无收盘日线时自动走实时。

### 3.4 人气

- 全市场人气快照（公开源优先同花顺 Top100）∩ 当日成分；保留原始 `rank` / `rank_diff`。
- 缺快照日：`missing_popular_snapshot`，**不借邻日**；不得把榜外当 0。
- 公开源无按日深表回放时，历史列空是诚实缺口，不是 bug。

### 3.5 梯队

- 全市场涨停/炸板池 ∩ 题材成分 + **收盘价校验封板**；日期轴与题材榜一致。
- 连板 L 与「N 天 M 板」区间描述分列；缺 tick 字段（如 fd_max）留空，不冒充。
- 与目标站盘中事件账本不对齐是预期；验收以本地清洗契约为准。

### 3.6 涨幅

- 成分股 N 日累计（默认 10，可选 5/20）；五档 ≥20%；空档与缺数据分开。
- 今日缺日线可用盘中价作期末（对齐盘中可出桶）。

### 3.7 K 线 + 驱动消息

- 有校准/板指真实 OHLC → 蜡烛；否则成分等权日净值 `series_kind=daily_nav`，**禁止用收盘价拼假 OHLC**。
- 驱动消息：列表按日展示摘要；正文优先本地 `plate_reason_daily`，缺正文回退 `boom_reason`。

## 4. 自研强度 ML-R1（并行能力，非本期默认 UI）

产品另有可解释自研口径 `formula_id=ml_r1`（相对收益 / 广度 / 量能 / 涨停扩散），详见历史 `docs/prd/ML题材轮动计算口径PRD.md`。

- 默认题材轮动 UI 当前主链是**开盘啦日榜 + 本地成分/行情**，不是宣称已还原目标站专有 score。
- ML-R1 仅在有验证目录与输入覆盖时发布；东财 14/15 **不能**改名成 17/18。

## 5. 数据与时效硬规则

1. 缺失 ≠ 0；旧行情 ≠ 停牌；采集时间 ≠ 行情时间；未来成分 ≠ 过去成员。
2. GET 只读已发布事实；历史缺数不在读路径偷偷回源补全（例外见 DATA.md）。
3. 状态分列：`final` / `partial_preview` / `provisional` / `missing` / `stale` 等；HTTP 200 ≠ 业务可用。
4. 历史验收：当年首个交易日 → 最新已完成交易日，**逐题材 × 逐指标 × 逐日**；单表总行数不能代替覆盖证明。

## 7. 明确遗留（不纳入本期「完成」）

- 人气深表（源站级数千行按日回放）与题材内截断深度对齐。
- 801 真实板指 OHLC 的长期自有源（校准层仅开发期可选）。
- 目标站专有强度/资金公式的逐字段等价证明。
- 盘中分时量能完整 ML-R1（无历史同时刻分母则不发布）。
- VIP/试用等产品账号能力与主工作台账号体系统一（迁仓后另排期）。
